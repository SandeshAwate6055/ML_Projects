# Insurance EDA Notebook

Files added:
- `insurance_eda.ipynb` — starter Jupyter notebook with multiple cells for EDA and a simple model.
- `requirements.txt` — Python packages used.

How to run:

1. (Optional) create and activate a virtual environment.

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Open the folder in VS Code and open `insurance_eda.ipynb`.

4. Run cells in order. Ensure `insurance.csv` is in the same folder.
